# 置身事内 · 知识库

> 一个仿维基百科式交叉链接的读书知识库，整理自兰小欢《置身事内：中国政府与经济发展》（上海人民出版社，2021）。
>
> 🌐 在线阅读：https://sharon-xx-lin.github.io/zishen-kb/

个人学习项目。将全书重组为「章节 — 概念 — 案例 — 人物」四类互相链接的词条，并配有可交互的知识图谱，方便自己和同好按线索查阅、回溯原文。

## 功能特性

- **全书章节**：前言、8 章正文、结束语与参考文献全文收录，含 24 张原书插图与脚注
- **71 个词条**：32 个核心概念（土地财政、分税制、融资平台……）、19 个案例与机构（京东方、光伏、合肥……）、20 位人物（周黎安、陆铭、林毅夫……），按全书词频排序
- **双向交叉链接**：章节正文中的词条自动链向词条页；词条页右侧「引用回链」面板展示各章节的原文摘录（高亮）
- **站内搜索**：标题 + 章节全文检索，`/` 键快捷聚焦
- **知识图谱**：82 节点 / 302 连边的力导向关系图（纯手写 canvas 实现，零依赖），支持悬停高亮、点击跳转、类型筛选、缩放拖拽
- **纯静态**：无后端、无构建依赖，任何静态托管可直接部署；资源带内容指纹（`?v=`）天然防缓存

## 目录结构

```
├── index.html            # 首页（统计、导航卡、高频词条、人物）
├── chapters/             # 前言 + 8 章 + 结束语 + 参考文献（211 条）
├── concepts/ cases/ people/   # 词条页
├── indexes/              # 章节总览 / 概念 / 案例 / 人物索引
├── quotes.html           # 全书金句（12 句，链接到原文出处）
├── graph.html            # 知识图谱
├── graph-data.json       # 图谱节点与连边数据
├── search-index.json     # 搜索索引
├── assets/img/           # 封面与原书插图
└── style.css / nav.js / search.js / graph.js
```

## 如何重建

站点由生成器从原书 PDF 文本自动构建（词条简介为人工撰写）：

```bash
# 1. 安装依赖（仅需 PyMuPDF）
pip3 install pymupdf

# 2. 在 generate.py 中配置你自己持有的原书 PDF 路径，然后运行
python3 generate.py

# 3. 本地预览（site 目录下）
cd site && python3 -m http.server 8765
```
